Weather App

AI Declaration
Claude was used in this project.

It was used to verify the 3 APIs that I have chosen to verify their functionality and limits, for example: “how often and how many days can OpenWeather’s API in the free tier fetch data about the weather”. 

No AI assistance or tools were used on the project.


Tools Used
Claude, Frappe, OpenWeather (API), MET Norway (API), OpenMeteo (API), W3schools, Github, Youtube


What was Done
Current weather and forecast: The OpenWeather API was used to display the current temperature, description, icon, wind and humidity, plus the 24-hour forecast in 3-hour increments. 

Two ways to choose a location: Search for any city’s names (upper or lowercase works). Alternatively, click “Use Your Current Position”. You will need to allow for the website to have access to your location (a pop up should appear). If your browser does not support such a feature it will throw an error.

Units switch: The default temperature is Celsius (°C), you also switch to Fahrenheit (°F) and Kelvin (K)

Favorites: To add a favorite city to “Favorites”, you would have already searched for the city, then click “Add To Favorites”. After that it will be saved and you will be able to view it in “Favorites”. To remove a city, you would need to either search for the city again or click in the “Favorites”, then the option to add to favorites would change to “Remove From Favorites”.

Theme: the page color changes depending on the temperature and weather

Error handling: different error codes were linked to error messages, for example wrong city name, no city inputted, lost connection etc.

Chart: Finally, there is a bar chart at the end comparing OpenWeather, MET Norway and OpenMeteo given temperature differences. Hover the mouse over the bars to view the data more accurately.

Additional: The features from the instructions are in separate JavaScript files instead of one to avoid cluttering.
